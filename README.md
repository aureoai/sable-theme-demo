# Sable: live demo

A static demo of **Sable**, a streetwear theme for Shopify, sold on Etsy by
AureoDigitals: https://www.etsy.com/listing/4603979611

Every page is the theme's own output with placeholder products and artwork.
The cart drawer works with one item; checkout, search and filtering need
Shopify and are switched off here.

This repository holds only the demo pages. The theme itself is not included.
